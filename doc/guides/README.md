# Guides

This folder collects the main user and reference guides for DualSPHysics v5.0.

## Available documents

- `DualSPHysics_v5.0_GUIDE.txt`  
  Entry point to the online DualSPHysics v5.0 guide (Wiki).
- `XML_GUIDE_v5.0.pdf`  
  General XML configuration guide.
- `XML_GUIDE_INLETOUTLET.pdf`  
  XML guide for inlet/outlet boundary configuration.
- `XML_GUIDE_MDBC.pdf`  
  XML guide for mDBC boundary configuration.
- `XML_GUIDE_MPHASE_NNEWTONIAN.pdf`  
  XML guide for multi-phase and non-Newtonian configuration.
- `PostprocessingCalculations_v5.0.pdf`  
  Post-processing calculations and workflow notes.
- `ExternalModelsConversion.pdf`  
  External model conversion instructions.
