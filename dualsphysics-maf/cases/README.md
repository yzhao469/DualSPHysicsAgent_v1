# cases

DualSPHysics XML case definitions used as templates or references.

## Files in this folder

| File | Main function / logic |
|---|---|
| `BaseCase_Def.xml` | Primary base XML template: contains defaults for constants/parameters and placeholder geometry meant to be replaced by `set_geometry`. |
| `CaseDebrisFlow2D_Def.xml` | Legacy/reference debris-flow 2D case definition with fixed geometry and parameter values. |
